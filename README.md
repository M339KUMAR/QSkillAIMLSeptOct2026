# QSkill AI/ML Internship – September & October

## 📌 Internship Overview

This repository contains the projects completed as part of the **QSkill AI/ML Internship** for the **September–October** internship period.

As part of the internship, participants are required to complete **at least 2 out of the 3 assigned AI/ML tasks** within the given timeframe.

## 🎯 Internship Tasks

The following tasks have been assigned:

- **Task 1 – Iris Flower Classification:** Build a Machine Learning classification model to classify Iris flowers into their respective species.
- **Task 2 – Email Spam-Ham Classification:** Build a Machine Learning/NLP model to classify emails or messages as **Spam** or **Ham (Not Spam)**.
- **Task 3 – House Price Prediction:** Build a Machine Learning regression model to predict house prices based on relevant property features.

## ✅ Completion Requirement

Participants must successfully complete **any two of the three tasks** before the internship deadline.

## 📊 Learning Objectives

The objective of these tasks is to gain practical experience in:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Machine Learning model development
- Model evaluation
- Classification techniques
- Regression techniques
- Natural Language Processing
- Presenting and documenting AI/ML projects
